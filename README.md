# Techfest IIT Bombay | Cyborg Landing Page

Responsive cyborg / HUD themed landing page, built as a Campus Ambassador task for Techfest, IIT Bombay.

- Live demo: https://bhavyakansal20.github.io/techfest-cyborg/
- Demo recording (Drive): PASTE-DRIVE-LINK-HERE
- Demo recording (in repo): [demo.mp4](demo.mp4)

## Features

- Boot-sequence loader and glitch-text hero
- Animated SVG cyborg eye (rotating rings, scan line, pulsing pupil)
- Interactive canvas circuit network that reacts to the cursor
- 3D tilt cards, scroll reveal animations, animated counters
- Fully responsive with mobile navigation
- Light / dark theme with a manual "Toggle Visor" switch
- Respects prefers-reduced-motion and device safe areas

## Tech

HTML5, CSS3 (custom properties, grid, flexbox, clip-path), vanilla JavaScript (Canvas API, IntersectionObserver). No frameworks, no build step.

## Run locally

Open `index.html` in any modern browser.
